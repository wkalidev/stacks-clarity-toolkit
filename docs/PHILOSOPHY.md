# Design Philosophy

## Safety First
Every function prioritizes safety over performance.
A few extra gas units is worth preventing a catastrophic overflow.

## Minimal Surface Area
The toolkit does one thing: safe math.
No governance, no tokens, no complex logic.

## Composability
Designed to be called from any Clarity contract.
Works with Clarity 1, 2, and 3.

## Transparency
All functions are read-only where possible.
No hidden state changes.
No admin functions needed.

## Battle-Tested
Used in production across the entire B2S ecosystem.
Zero incidents since mainnet launch.
