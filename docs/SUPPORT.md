# Support

## Bug Reports
Open an issue on GitHub with:
- Contract function that failed
- Input values used
- Expected vs actual result
- Transaction ID if available

## Feature Requests
Open an issue labeled "enhancement" with:
- Use case description
- Proposed function signature
- Example usage
