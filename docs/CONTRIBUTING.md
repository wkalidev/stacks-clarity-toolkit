# Contributing to stacks-clarity-toolkit

## Guidelines
1. All functions must be safe (no panics)
2. Add tests for every new function
3. Document gas costs
4. Maintain backwards compatibility

## Adding a new function
1. Add to toolkit-math contract
2. Write Clarinet tests
3. Update FUNCTIONS.md
4. Update CHANGELOG.md

## Testing
clarinet test

## PR requirements
- Tests pass
- Documentation updated
- No breaking changes
